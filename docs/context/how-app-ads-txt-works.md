# Как устроен файл app-ads.txt

Документ для человека, который с рекламой в приложениях раньше не сталкивался.

Рядом лежит живой пример: [`example-app-ads.txt`](./example-app-ads.txt). Все имена студий и сетей ниже — учебные, кроме Google / AdMob.

## Сначала сцена

Ты открываешь игру. Между уровнями появляется реклама кроссовок.

В этой сцене четыре роли:

1. **Игрок** — смотрит рекламу.
2. **Студия, которая сделала игру** — хочет заработать на показах.
3. **Бренд** (Nike, банк, другая игра) — хочет эти показы купить.
4. **Рекламная биржа** (часто Google) — площадка, где студия и бренд встречаются. Биржа не владеет игрой и обычно не является автором объявления. Она проводит аукцион и берёт комиссию.

Студия продаёт не «рекламу», а **слот**: место на экране на один показ. Объявление в этот слот подставляет победитель аукциона.

## Учебные персонажи

Дальше везде одни и те же вымышленные компании. Это не названия из реального файла и не термины стандарта — просто имена, чтобы было кого называть.

| Имя | Кто это | Чего у них нет / есть |
|---|---|---|
| **SuperGames** | Студия. Сделали игру, хотят монетизировать рекламой. Их ещё называют **издателем** | Есть приложение и слоты. Нет своей биржи |
| **example-publisher.com** | Официальный сайт SuperGames | Не биржа и не приложение. Просто сайт студии |
| **Google / AdMob** (`google.com`) | Реальная рекламная биржа | Есть аукцион и счета клиентов. Нет игры SuperGames |
| **MegaMediation** (`megamediation.com`) | Вымышленная **рекламная сеть** (посредник). Живые аналоги: AppLovin, Unity Ads, ironSource | Нет своих слотов в игре SuperGames. Есть отдел продаж и свой счёт на Google. Это **не** другая игра |
| **Бренд** | Кто платит за показ | В `app-ads.txt` его нет |

Коротко: SuperGames владеет слотами. Google — касса, где слоты продают. MegaMediation — перекупщик чужих слотов, не конкурент-приложение.

## Зачем тогда текстовый файл

Мошенник может сказать бирже: «я SuperGames, продавайте мою рекламу». Чтобы отсечь это, студия публикует на своём сайте открытый список: **кому разрешено продавать слоты её приложений**.

Файл всегда лежит так:

```
https://example-publisher.com/app-ads.txt
```

Это не каталог объявлений и не список приложений. Это белый список **счетов на биржах**.

Откуда вообще берётся `example-publisher.com`? Со страницы приложения в App Store / Google Play: у студии указан сайт разработчика. По нему и ищут `app-ads.txt`.

## Как читать одну строку

Строка — одна запись «этот счёт на этой бирже имеет право продавать наши слоты».

```
google.com, pub-1234567890123456, DIRECT, f08c47fec0942fa0
   │                │                │            │
   │                │                │            └── необязательно: код биржи в справочнике IAB
   │                │                └── DIRECT = это наш собственный счёт
   │                └── номер счёта SuperGames внутри Google (его выдаёт Google при регистрации)
   └── биржа, на которой идёт продажа
```

Поля через запятую. Смысл полей:

| Поле | Что это | Чем не является |
|---|---|---|
| `google.com` | Домен биржи | Не сайт SuperGames |
| `pub-1234567890123456` | Логин SuperGames **в Google**. У Meta будет просто число, у других — короткий код | Не ID игры (Bundle ID) и не домен сайта |
| `DIRECT` или `RESELLER` | Чей это счёт: студии или посредника | Не «вид рекламы» |
| `f08c47fec0942fa0` | Необязательный код Google в индустрии | Можно не писать, строка всё равно живая |

Строка выше читается так:

> На бирже Google студия SuperGames сидит под счётом `pub-1234567890123456` и продаёт слоты **сама**.

Что происходит в момент показа:

1. Игрок открывает игру SuperGames.
2. Встроенный рекламный SDK стучится в Google: «есть слот».
3. Google (и покупатели) открывают `https://example-publisher.com/app-ads.txt`.
4. Ищут строку `google.com` + этот `pub-…`.
5. Нашли — слот идёт на аукцион. Побеждает бренд. SuperGames получает долю, Google — комиссию.

Строки с `#` — комментарии. Строки вроде `CONTACT=...` — контакты, не продавцы.

## Зачем в файле две строки про Google

У SuperGames свой счёт в Google. Отдельно они наняли сеть MegaMediation: та умеет продавать показы пачками (много игр сразу) и приводит бренды, которые со студией напрямую не работают.

MegaMediation **не ставит баннер в свою игру**. Она берёт слот SuperGames и выставляет его на **той же Google**, но уже со **своего** Google-счёта `pub-9988776655443322`.

```
# SuperGames продаёт сама, своим Google-счётом
google.com, pub-1234567890123456, DIRECT, f08c47fec0942fa0

# MegaMediation продаёт те же слоты SuperGames на Google, но своим Google-счётом
google.com, pub-9988776655443322, RESELLER, f08c47fec0942fa0

# третий канал: покупатель идёт не в Google, а на собственную биржу MegaMediation
megamediation.com, 9675, DIRECT
```

`RESELLER` значит: этот счёт **не принадлежит** SuperGames. SuperGames лишь написала: «продавать с этого чужого счёта тоже можно».

Имя MegaMediation в средней строке специально не стоит. Файл говорит не «мы дружим с фирмой X», а «счёт `pub-9988` на Google — наш официальный продавец». Чья это компания, смотрят уже в справочнике Google (`sellers.json`).

Почему нельзя заменить среднюю строку на одну `megamediation.com, …`? Потому что покупатель на аукционе **Google** проверяет пару «биржа = google.com + счёт на Google». Строка про `megamediation.com` разрешает продажи **на кассе MegaMediation**, а не те, которые сеть прогнала через Google. Это три разных кассы/пути, не дубли одной мысли.

## Зачем посредник, если Google и так есть

Google — общая труба. Выгода не в «другой Google», а в **другом продавце на той же трубе**.

```
напрямую:     бренд  →  Google  →  SuperGames (счёт pub-1234)
через сеть:   бренд  →  MegaMediation  →  Google  →  SuperGames
```

Зачем SuperGames второй путь:

- одна маленькая игра бренду неинтересна; сеть продаёт корзину из сотен игр;
- у сети свои контракты: бренд купил у MegaMediation «показы в казуальных играх» и даже не знает про SuperGames;
- такой бренд **не** купит путь `Google → SuperGames` напрямую — у него договор с сетью, не со студией.

Без строки `RESELLER` продажи MegaMediation через Google для этой игры выглядят как подделка: «кто-то чужой продаёт слоты SuperGames без разрешения».
